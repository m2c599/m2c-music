app for the music by m2c

Ta musique, YouTube et tes playlists dans une seule application pour Windows.

⬇ Télécharger pour Windows

Gratuit · Windows 10 et 11

🔎 Recherche YouTube

Cherche n'importe quelle musique et écoute-la directement dans l'application.

🎧 Ta propre musique

Importe tes fichiers audio, crée des playlists et retrouve-les à chaque ouverture.

🛠 Personnalisable

Change les textes, les couleurs, le fond espace et le volume depuis la page Admin.

Installer en 3 étapes

  1. Clique sur Télécharger pour Windows et récupère le fichier m2c-music-installateur.exe.
  2. Double-clique dessus. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires, puis sur Exécuter quand même. C'est normal : l'application n'est pas encore signée par un éditeur reconnu.
  3. Ouvre m2c music avec le raccourci créé sur ton bureau.

Bon à savoir

Ta bibliothèque et tes réglages restent sur ton ordinateur. La recherche YouTube demande une clé gratuite à créer une seule fois :

Comment obtenir ma clé YouTube ?
  1. Va sur console.cloud.google.com et connecte-toi avec un compte Google.
  2. Crée un nouveau projet (sélecteur de projet en haut, puis « Nouveau projet »).
  3. Dans « API et services », puis « Bibliothèque », cherche YouTube Data API v3 et clique sur « Activer ».
  4. Dans « Identifiants », clique sur « Créer des identifiants », puis « Clé API », et copie la clé.
  5. Dans l'application, ouvre la page Bibliothèque, clique sur ⚙ à côté de la recherche et colle la clé.

Limite gratuite : environ 100 recherches par jour.
